# PRP370 Digital Portfolio — Tech Empower Labs

A GitHub Pages starter portfolio for Project Presentation 3.

## Files
- `index.html`: portfolio home page
- `about.html`: student introduction and learning journey
- `evidence/`: five assessment areas
- `css/style.css`: responsive styling
- `js/script.js`: mobile navigation behaviour
- `images/`: add your screenshots and other visual artefacts

## Before publishing
1. Replace all bracketed placeholders with your own accurate details.
2. Add genuine project artefacts, screenshots and links.
3. Write personal reflections based on what you actually did and learned.
4. Check that no private information or credentials appear in screenshots.
5. Test all navigation links on desktop and mobile.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload the contents of this folder (not just the ZIP file).
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.
5. Wait for the published URL to appear in the Pages section and test it.

The assessment brief requires submission of the GitHub Pages link on Blackboard. Follow your lecturer's instructions for the final submission.
