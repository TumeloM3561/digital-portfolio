ASSESSMENT AREA 02

User Stories and Tasks

Show how user needs were translated into manageable tasks.

Evidence

Add your actual user stories and their task/checklist breakdown. Include a Trello screenshot or a link if available.

User story format

As a [type of user], I want [a goal or feature], so that [a benefit].

Evidence checklist

  • Stories written from the user's perspective
  • Tasks that clearly support each story
  • Priority or acceptance criteria where used
  • Evidence of task tracking in Trello or another agreed tool

My reflection

Reflection prompts

  • How did you identify user needs?
  • How did you break larger requirements into tasks?
  • What did you learn about writing clear stories?
  • What would you change to make the tasks easier to track?

Use your actual stories and personal experience. Do not state that all stories were completed unless your board shows that.
